# Roadmap

Build order for The Athlete by Rory Gibbs. Each workstream gets its own chat, with this repo attached.
Start each chat with: "Read CLAUDE.md and ROADMAP.md, then let's work on step N."

## Order

1. **School presentations (online first).** Fastest route to income, and the core content for everything else.
   - Athlete talk: 30 minutes for young athletes, then live Q&A.
   - Parent evening: 30 minutes on supporting your athlete at home and through the holidays.
   - Deliverables: slide decks, speaker notes, a one page booking sheet for schools, follow up email.
   - Website: the Schools page already lists both online talks. Add booking and pricing once decided.
2. **Online Athlete Deck.** Release cards digitally before printing.
   - Card content spreadsheet (title, section, lesson, "try this" action, illustration brief).
   - One fixed card template (front and back), illustrations generated without text and dropped in.
   - Web version on the site: a few free cards, the rest behind email signup or a small payment.
   - The physical deck comes later, once the content is proven (Alibaba print, Amazon FBA).
3. **Content engine.** Turn each card and talk into posts, threads, polls and Story quizzes.
   Comment keyword to receive a free card, to grow the email list.
4. **Core course.** Built from the talks and the deck. One version for athletes, one for parents.
   Host on a course platform first (for example Thinkific, Podia or Kajabi) rather than custom code.
5. **Sport specific courses.** Spin offs of the core course. Build the most voted sport first
   (the Courses page waitlist collects votes).
6. **The app, "your coach in your pocket".** Last, once the content exists. Start with a simple web app
   built from the deck and course material, then go native if demand is there.
7. **Physical deck** in parallel with steps 4 to 6, once card size and supplier are chosen.
